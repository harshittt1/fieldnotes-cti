Threat Indicators & Hashes
(raw_indicators, hashes)		 [EMBEDDED] { raw_indicators: ['198.51...'], hashes: {sha256: '...'} } Bounded 1-to-few relationship. Indicators are always queried and displayed alongside the threat report. Atomic single-document reads avoid costly joins.
MITRE ATT&CK Tactics
(mitre_tactics)		 [EMBEDDED] { mitre_tactics: ['Initial Access', 'Persistence'] } Fixed taxonomy of adversary techniques. High read-to-write ratio, bounded array size.
Adversary Threat Groups [REFERENCED] { organization: { orgId: 'ORG-01', name: 'CISA' } } Unbounded 1-to-many relationship. Organizations publish thousands of reports. Embedding would duplicate metadata and risk hitting 16MB.
External Intelligence Feeds [REFERENCED] { sourceFeed: { feedId: 'FEED-01', endpoint: '...' } } Decouples data ingestion pipelines from historical threat records. Allows updating feed ingestion health independently.
